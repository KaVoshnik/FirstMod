# FirstMod

**Песочница и чит-меню для Risk of Rain 2.**

## Почему FirstMod

- **Всё в одном окне.** Нажмите **N**: вкладки «Игрок», «Передвижение», «Бой», «Мир», «Предметы», «Спавн», «Игроки», «Персонаж» и «Настройки».
- **Рассчитан на мультиплеер.** Локальные функции (полёт, noclip, скорость, ESP) работают у любого игрока. Серверные работают для всех, как только мод стоит у **хоста**.
- **Выглядит как инструмент, а не как консоль отладки.** Плитки с иконками для предметов и существ, поиск, фильтр по редкости, подсказки, интерфейс на русском и английском.
- **Безопасно по умолчанию.** Переключатели не сохраняются: читы не включаются сами при запуске.

## Возможности

| Вкладка | Что можно делать |
|---|---|
| **Игрок** | Бессмертие, лечение и воскрешение, деньги, лунные монеты, бесплатные покупки, уровень команды. Цель: я / все / конкретный игрок. |
| **Передвижение** | Скорость, высота прыжка, бесконечные прыжки, полёт, noclip, без урона от падения, телепорт в прицел / к телепортеру / к ближайшему сундуку, магнит лута, забег по сундукам. |
| **Бой** | Ваншот, скорость атаки, 100% крит, мгновенный кулдаун, урон / броня / регенерация / макс. здоровье, убить всех, убить цель в прицеле, заморозка ИИ врагов. |
| **Мир** | Скорость игры, зарядка телепорта, следующий / повтор этапа, таймер забега, директор (стоп спавна, кредиты, запуск босса), пройдено этапов, сложность, артефакты, выбор этапа, порталы (синий / золотой / небесный / войд). |
| **Предметы** | Каталог предметов и экипировки с плитками, фильтр по редкости, подсказки, поиск по названию и описанию. Выдать, убрать, очистить инвентарь. |
| **Спавн** | **Существа** (враги или союзники, аффикс элиты, в точку прицела), **Объекты** (сундуки, святыни, принтеры...), **Дроны** (добавить союзниками, убрать своих по одному или всех сразу). |
| **Игроки** | Телепорт между игроками, сохранённые точки телепорта (хранятся между сессиями). |
| **Персонаж** | Смена выжившего, скина и вариантов скиллов посреди забега, сохранение и загрузка билдов. |
| **ESP** | Подписи сундуков, святынь, принтеров и телепортера (тип, цена, расстояние), рамки и полоски здоровья врагов. Только у вас. |

Тексты из игры (названия предметов, подсказки, этапы, персонажи...) следуют языку меню: если переключить меню на английский, предметы тоже будут на английском.

## Быстрый старт

1. Установите через **Thunderstore Mod Manager** (рекомендуется) или положите `FirstMod.dll` в `BepInEx/plugins/FirstMod/`.
2. Запустите игру и нажмите **N** в забеге или в лобби.
3. Играете с друзьями? Серверные функции работают, если мод стоит у **хоста**.

### Горячие клавиши (меняются в конфиге)

| Клавиша | Действие |
|---|---|
| **N** | Открыть / закрыть меню |
| **F5** | Бессмертие |
| **F6** | Полёт |
| **F7** | Noclip |
| **F8** | Телепорт в прицел |
| **F9** | Убить цель в прицеле (хост) |
| **F10** | HUD с включёнными функциями |
| **F11** | ESP |

Настройки и клавиши: `BepInEx/config/com.Kavoshnik.firstmod.cfg`.
Сохранённые билды: `BepInEx/config/FirstMod_builds/`.

### Мультиплеер коротко

| Работает у любого игрока | Нужен мод у хоста |
|---|---|
| Полёт, noclip, скорость, прыжок, бесконечные прыжки, ESP, забег по сундукам, телепорт «к нему», союзные дроны, пресеты билдов для себя | Спавн врагов, объекты, управление забегом (сложность, артефакты, этапы), директор, бессмертие / ваншот для других, «к себе», изменение здоровья / брони / регенерации |

## Если что-то не работает

**Управление перестало работать или в логе полно `MissingFieldException ... jumpWasClaimed`.**
Устаревший мод **SeekersPatcher** конфликтует с текущей версией игры. Удалите его в Thunderstore Mod Manager кнопкой *Uninstall SeekersPatcher only* и не обновляйте и не переустанавливайте `bbepis-BepInExPack`, пока он его требует.

**У части предметов вместо иконки цветной квадрат.**
Некоторым иконкам нужно несколько секунд, чтобы появиться после открытия меню. Если не появились, приложите `BepInEx/LogOutput.log` к issue.

**Меню работает, а серверная функция ничего не делает.**
Скорее всего, вы клиент, а у хоста нет мода.

Если проблема другая, быстрее всего поможет лог: `BepInEx/LogOutput.log` в папке профиля (Thunderstore Mod Manager: *Settings* -> *Browse profile folder*).
